# GitHub Pages Kurulum

## Hızlı Kurulum

1. GitHub'da repository'nize gidin: `https://github.com/Okkahai/0lon-Web`
2. **Settings** → **Pages**
3. **Source:** "Deploy from a branch" seçin
4. **Branch:** `main` seçin
5. **Folder:** `/ (root)` seçin
6. **Save**

Site birkaç dakika içinde canlı olacak: `https://okkahai.github.io/0lon-Web`
